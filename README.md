# LinguaSync Pro - AI 视频同声传译

Chrome 扩展，在任何视频网页上浮现 AI 同声传译悬浮窗。播放外语视频时自动识别语音、实时翻译为中文，字幕直接叠加在视频画面上。

## 功能一览

- **实时语音识别** — 基于 Web Speech API，支持英语、日语、韩语等 8 种语言
- **流式翻译** — 150ms 防抖 + 上下文增强（最近 3 句历史），翻译连贯自然
- **视频内嵌字幕** — 原文 + 译文直接叠加在视频底部，半透明背景不遮挡画面
- **标签页音频直采** — 通过 getDisplayMedia 捕获标签页音频 +8dB 增益放大，不依赖麦克风外放
- **自动启停** — 视频播放自动开始同传，暂停自动停止
- **会议记录** — 带时间戳的原文 + 译文双语记录，实时滚动
- **智能待办** — 从翻译文本中自动提取行动指令（"需要"、"负责"、"完成"等），支持 OpenAI GPT 增强提取
- **翻译导出** — 一键导出为 TXT 文件

## 安装

### 从源码构建

```bash
git clone https://github.com/qq1906198507-ai/AIst.git
cd AIst
npm install
npm run build
```

构建产物在 `dist/` 目录。

### 加载到 Chrome

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择项目中的 `dist` 文件夹
5. 扩展安装完成

## 使用方法

### 基本操作

打开任意含视频的网页（B 站、YouTube、Coursera 等），LinguaSync Pro 悬浮窗会自动出现在视频下方。

**开始同传：** 点击「开始同传」按钮，或按 `Alt+T`。视频播放时会自动开始。

**查看记录：** 点击右侧下拉箭头 `↓` 展开面板，「会议记录」标签页显示所有翻译历史。

**导出记录：** 点击「导出」按钮，或按 `Alt+E`，下载为 TXT 文件。

### 音频模式

悬浮窗有两种音频采集模式，点击工具栏的「麦克风」按钮切换：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **麦克风** | 通过系统麦克风拾音 | 外放视频、会议通话 |
| **标签页音频** | 直接捕获浏览器标签页音频 | 戴耳机看视频（推荐） |

标签页音频模式会通过 Web Audio API 对音频做 +8dB 增益放大，轻声内容也能被识别到。首次切换时浏览器会弹出屏幕共享选择框，选择当前标签页并勾选「共享音频」。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+T` | 开始 / 停止同传 |
| `Alt+E` | 导出翻译记录 |

### 设置

点击 Chrome 工具栏的扩展图标，打开设置面板：

- **源语言** — 选择视频的语言（英语、日语、韩语、法语、德语、西班牙语、俄语）
- **自动开始** — 检测到视频播放时是否自动启动同传

## 智能待办

翻译文本中包含行动指令时，系统会自动提取为待办事项，显示在「智能待办」标签页中。

**关键词匹配**（默认启用）：识别包含"需要"、"负责"、"完成"、"跟进"、"准备"、"提交"等关键词的句子。

**AI 增强提取**（需配置 OpenAI API Key）：通过 GPT 模型更精准地从上下文提取待办。在 popup 设置中填入 API Key 即可启用。

待办支持勾选完成，新待办有橙色圆点提醒。

## 技术架构

```
┌─────────────────────────────────────────────┐
│  Content Script (注入到视频页面)              │
│  ├─ 视频检测 (MutationObserver + 轮询)       │
│  ├─ TabAudioCapture (getDisplayMedia + 增益) │
│  ├─ SpeechEngine (Web Speech API)           │
│  ├─ SubtitleOverlay (视频内嵌字幕)           │
│  ├─ FloatingWidget (悬浮控制面板)            │
│  └─ 翻译防抖 (150ms) + 上下文增强            │
├─────────────────────────────────────────────┤
│  Background Service Worker                  │
│  ├─ 翻译分发 (MyMemory / OpenAI GPT)        │
│  ├─ AI 待办提取 (OpenAI GPT)                │
│  ├─ tabCapture 协调                         │
│  └─ 快捷键转发                              │
├─────────────────────────────────────────────┤
│  Popup (扩展弹出页)                          │
│  └─ 源语言 / 自动开始设置                    │
└─────────────────────────────────────────────┘
```

**技术栈：** TypeScript + Vite + Tailwind CSS v4 + Chrome Extension Manifest V3

## 常见问题

**Q: 悬浮窗没有出现？**
确保页面中有 `<video>` 元素且尺寸大于 200×100px。部分网站的播放器使用非标准实现，可能无法自动检测。

**Q: 语音识别不灵敏？**
切换到「标签页音频」模式，该模式通过 GainNode 放大 +8dB，识别效果明显优于麦克风模式。

**Q: 标签页音频切换后没声音？**
首次使用时浏览器会弹出共享选择框，需要选择当前标签页并勾选「同时共享标签页音频」。

**Q: 翻译质量不够好？**
在 popup 设置中配置 OpenAI API Key，使用 GPT 翻译可获得更高质量的上下文感知翻译。

**Q: 扩展更新后界面没变？**
在 `chrome://extensions/` 刷新扩展后，需要**关闭**视频标签页再**重新打开**，内容脚本才会加载最新版本。
