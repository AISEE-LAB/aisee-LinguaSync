# LinguaSync Pro - AI 同声传译

一款沉浸式同声传译悬浮窗组件，模拟多人会议场景下的实时翻译体验。

## 功能特性

- **悬浮字幕窗**：可拖拽的半透明字幕悬浮窗，适配任何视频会议场景
- **实时草稿修正**：展示从草稿到精校的识别过程
- **多人声纹识别**：区分不同说话人并以颜色标识
- **私有词库高亮**：悬停术语查看私有词库释义
- **智能待办嗅探**：AI 自动从会议内容中提取任务分配
- **跨语言嘴替**：按住说话，实时反向翻译输出
- **手机副屏**：扫码连接手机作为实时提词器
- **会议记录**：完整的翻译历史和会议回顾

## 快速开始

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/` 即可体验。

## 技术栈

- React + TypeScript + Vite
- Tailwind CSS v4
- Lucide React 图标库
